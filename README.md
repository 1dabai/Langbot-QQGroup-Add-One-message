# Langbot-QQGroup-Add-One-message
适配 **LangBot** 的 QQ 群聊「同消息聚合回复」插件，**不兼容 QQ 官方机器人 API**，仅支持第三方协议端部署使用。

---

## 📌 项目简介
一款群聊触发工具：群内多名用户发送**完全相同的消息**时，自动触发预设回复并发送到群内。

## ✨ 核心功能
- **同消息集体触发**
  同一个 QQ 群内，两名及以上不同用户发送相同内容，即可触发预设统一回复。
- **内置 5 分钟冷却**
  触发后该条消息进入冷却期，冷却期间重复发送不再响应，避免刷屏与重复回复。

## 🎯 适用场景
- 群内统一口令应答
- 群活动集体互动
- 社群统一话术回复
